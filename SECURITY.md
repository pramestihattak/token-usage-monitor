# Security Policy

## Supported versions

Security fixes are provided for the latest published release.

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/pramestihattak/token-usage-monitor/security/advisories/new).

Do not include credentials, private prompts, local history files, or other sensitive data in a public issue. Include only the minimum reproduction details needed to understand the problem. If logs are relevant, redact account identifiers, paths, tokens, and conversation content.

After a report is received, the maintainer will assess its impact, coordinate a fix when appropriate, and publish an advisory after affected users can update.
